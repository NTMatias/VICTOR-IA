# Componentes de terceros

Las licencias y condiciones de los componentes de terceros siguen perteneciendo a sus titulares. La publicación de VICTOR.IA no cambia esas condiciones.

| Componente | Aviso conservado o referencia |
| --- | --- |
| Python | `python/LICENSE.txt` en la distribución portátil. |
| PySide6 / Qt | Licencias y metadatos incluidos en los paquetes de la distribución portátil; [Qt Licensing](https://doc.qt.io/qtforpython-6/licenses.html). |
| Node.js | `runtime/node/LICENSE` en el portátil. |
| Microsoft WebView2 | `victor/gui/webview2/LICENSE.txt`, `PROVENANCE.txt`, SDK oficial fijado y runtime Microsoft con sus avisos. |
| xterm.js y addon-fit | `victor/gui/terminal/vendor/XTERM-LICENSE` y `FIT-LICENSE`. |
| Inter y IBM Plex Mono | Archivos OFL junto a las fuentes en `victor/gui/assets`. |
| Iconos de marca | `victor/gui/assets/BRAND-LICENSE.md`. Los nombres y marcas pertenecen a sus titulares. |
| Codex CLI | Binario oficial sin modificar, [licencia Apache 2.0](https://github.com/openai/codex/blob/main/LICENSE), avisos en `data/agent_cli` del portátil. |
| Claude Code | CLI oficial sin modificar; su LICENSE y [condiciones oficiales](https://code.claude.com/docs/en/legal-and-compliance). La autenticación se realiza directamente con Anthropic. |
| Whisper y bibliotecas Python | Licencias/metadatos conservados en `python/Lib/site-packages` del portátil; el modelo tiene su propia procedencia. |

Cada usuario usa sus cuentas y claves propias. No se redistribuyen credenciales ni se intermedia el saldo de los servicios. Los componentes propietarios no se relicencian como código de VICTOR.IA.
